# Football Betting Model

A sophisticated machine learning system that predicts outcomes in English football
matches and identifies profitable betting opportunities through statistical arbitrage.

## Features

- Download historical match data spanning 16 years
- Train XGBoost and LightGBM ensemble models
- Run comprehensive backtesting simulations
- Fetch live odds from The Odds API
- Identify value betting opportunities with real-time analysis

## Usage

1. Click "Download Data" to acquire historical match datasets
2. Click "Train Models" to build prediction algorithms
3. Click "Run Backtest" to validate strategy performance
4. Enter your Odds API key for live market data
5. Click "Find Value Bets" to discover profitable opportunities

## Performance

The system achieved 29.4% return on investment during backtesting, with 48%
prediction accuracy and well-calibrated probability estimates validated through
comprehensive statistical analysis.
